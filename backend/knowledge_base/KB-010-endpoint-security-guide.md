# Endpoint Security Guide (Employee Guide)

> **Simulated content.** Fictional sample documentation for a demonstration
> system.

## 1. Keep the protection agent running

Every managed device runs an endpoint protection agent. It must always be:

* installed and running — you should see its icon in the system tray;
* up to date with the latest signature and engine version;
* allowed to quarantine detected files automatically.

If the agent reports "protection disabled", "licence expired" or shows a red
status, contact the IT service desk. Do **not** continue working with protection
disabled.

## 2. Keep the system updated

* Install operating system updates within 7 days of release.
* Restart when prompted — a pending restart leaves the device unprotected
  against the patched issue.
* Keep browsers and common applications updated; unapproved browser extensions
  are blocked by policy.
* Remove software you no longer use.

## 3. Safe browsing and downloads

* Download software only from the company software catalogue or the vendor's
  official site.
* Do not install "cracked", "portable" or "free full version" software — this is
  one of the most common malware vectors.
* Do not approve a browser permission (notifications, camera, clipboard) unless
  the site genuinely needs it.
* Treat a browser notification saying "your device is infected, call this
  number" as a scam. It is not a real alert.
* Never call a phone number presented by a pop-up or a web page.

## 4. Removable media

* Do not connect an unknown USB device found in a car park, a lobby or a
  conference bag. This is a standard attack technique.
* Company-issued encrypted USB drives only; personal drives are not permitted.
* Do not connect a phone by USB to charge it on a managed device.

## 5. Recognising an infected device

Warning signs include:

* unexpected pop-up windows, especially security or "update" pop-ups;
* the browser home page or default search engine changed on its own;
* new toolbars, extensions or programs you did not install;
* the protection agent disabled itself, or its window will not open;
* unusual fan noise, disk activity or slowness with no explanation;
* files renamed, duplicated or replaced by an unusual extension;
* a ransom note or a message demanding payment;
* documents or photos that suddenly cannot be opened.

## 6. Immediate steps if you suspect malware

1. **Disconnect from the network** — unplug the network cable, or turn off Wi-Fi.
   This stops data exfiltration and the spread to shared drives.
2. **Do not** try to clean the machine yourself, and do not run a "free cleaner"
   downloaded from the internet.
3. **Do not** restart if you can avoid it — evidence in memory is lost on
   reboot.
4. **Do not** plug in a USB drive to copy files off the machine.
5. Photograph any error message or ransom note with your phone.
6. Report immediately to the IT service desk and the security team, describing
   what you saw and when it started.
7. Use a different, trusted device to change your password if you were asked to
   enter credentials.

## 7. Working safely day to day

* Lock your screen whenever you leave your desk.
* Never leave an unlocked device unattended in a public place.
* Do not share your device or your account with a colleague.
* Report anything that seems wrong, even if you are not sure. A quick report is
  cheap; a missed infection is not.
